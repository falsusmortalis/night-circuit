# Музыка игры «На нычке»

Сюда загружай свои авторские музыкальные треки проекта **prod. by A-Del**.

## Как добавлять музыку
1. Нажми **Add file → Upload files** в корне репозитория.
2. Перейди в папку `assets/audio/` (если её нет — создай её, загрузив этот README первым).
3. Перетащи сюда аудиофайлы.
4. Нажми **Commit changes**.

## Рекомендуемые форматы
- MP3 — компактный и удобный для браузера.
- OGG — хорошая альтернатива.
- WAV — лучше оставить для исходников; для веб-публикации он может быть слишком тяжёлым.

## Имена файлов
Используй латиницу, цифры, дефисы и подчёркивания, например:
- `a-del-track-01.mp3`
- `a-del-night-drive.ogg`

Не используй пробелы и кириллицу в именах файлов.

## Важно
Загружай сюда только те записи, на которые у тебя есть права для публикации и воспроизведения в игре. Эта папка предназначена для музыкальных файлов, которые будут доступны посетителям опубликованной игры.
