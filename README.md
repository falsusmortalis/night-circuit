# НА НЫЧКЕ

Авторская инди-игра о Феодосии будущего, одиночестве, памяти и маленьких личных тайнах.

Музыка: **prod. by A-Del** — авторские композиции, которые станут частью атмосферы игрового мира.

## Новое направление проекта
- **Место:** Феодосия — узнаваемая, но переосмысленная как город будущего: море, набережная, старые улицы, холмы, порт, дворы и знакомые городские детали.
- **Настроение:** одиночество, нежность, боль и странное удовольствие от пребывания наедине с собой.
- **Визуальный стиль:** небольшая стилизованная мультяшность, мягкие формы, выразительные цвета, приятная кинематографичная картинка. Не фотореализм и не мрачный киберпанк-клон.
- **Геймплей:** не обязательно непрерывно перемещаться по большому городу. Исследование может строиться из небольших вручную сделанных локаций, комнат, дворов, набережной, крыши, остановки и интерактивных воспоминаний.
- **Пасхалки:** личные детали, предметы, фразы, места и события из жизни автора — спрятанные так, чтобы они работали и как самостоятельные маленькие истории.

## Музыка
Авторские треки проекта хранятся в `assets/audio/`. В этой папке есть инструкция по загрузке. Музыка должна быть встроена в игру как непрерывный саундтрек с управлением громкостью и переключением композиций.

## Запуск
Статический сайт. Для локальной разработки используйте HTTP-сервер (например, Live Server в VS Code). Текущая техническая сцена использует Three.js с CDN, поэтому для первого запуска требуется интернет.

## План разработки
1. Утвердить художественный стиль и визуальный язык Феодосии будущего.
2. Сделать небольшой выразительный игровой фрагмент — например, вечерняя набережная, двор и личная комната.
3. Встроить авторскую музыку prod. by A-Del.
4. Добавить исследуемые предметы, пасхалки и интерактивные воспоминания.
5. Решить, какие районы и способы перемещения действительно нужны игре.

## Текущий статус
В репозитории пока находится ранний технический прототип с временным блок-аутом. Он не отражает новое художественное направление и будет постепенно заменён.
