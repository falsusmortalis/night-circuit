# НОЧНОЙ КОНТУР / NIGHT CIRCUIT

Браузерная sandbox-игра о свободном исследовании альтернативного Краснодара 2049 года.

## Художественное направление
Кинематографичный неонуар: около 70% атмосферы Blade Runner 2049 и 30% визуальной энергии Cyberpunk 2077, с узнаваемой южнороссийской городской средой. Самостоятельный мир и оригинальные ассеты.

## Запуск
Статический сайт. Для локальной разработки используйте любой HTTP-сервер (например, Live Server в VS Code). Three.js загружается с jsDelivr CDN, поэтому требуется интернет.

## Управление
- WASD — движение
- Мышь / свайп — обзор
- Q / E — высота
- Shift — ускорение
- На сенсорном экране — виртуальный джойстик и кнопки высоты

## План
1. Вертикальный срез Восточно-Кругликовского района и парка Галицкого.
2. Качественные GLB/GLTF модели, PBR-материалы, растительность, транспорт и персонажи.
3. Атмосферное освещение, туман, отражения, городской звук и оригинальные радиостанции.
4. Секреты, аномалии и исследовательские точки.
5. После полировки Краснодара — Ростов-на-Дону и Санкт-Петербург.

## Текущий статус
Ранняя техническая сборка: свободная камера, процедурный блок-аут улиц, парка и стадиона, тестовые автомобили и NPC-заглушки. Это фундамент для художественного прохода, а не финальная графика.
